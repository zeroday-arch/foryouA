ALEYNA WEBSITE

1. Entpacke den ZIP-Ordner.
2. Öffne index.html im Browser.
3. Für eine Veröffentlichung kannst du den ganzen Ordner bei Netlify, GitHub Pages oder einem Webhoster hochladen.

Bilder ändern:
In index.html findest du den Bereich "Galerie". Die farbigen Platzhalter können später durch echte Bilder ersetzt werden.

Texte ändern:
Öffne index.html mit einem Texteditor und ersetze die gewünschten Texte.

Hinweis:
Die 3D-Animation nutzt Three.js über ein CDN. Dafür ist eine Internetverbindung erforderlich.
